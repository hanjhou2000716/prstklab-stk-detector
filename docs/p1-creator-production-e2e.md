# Creator production E2E

The offline production acceptance exercises a sanitized public creator record
through release lineage, creator artifact generation, and the creator delivery
contract. The fixture is intentionally unverified content: it proves that
publication preserves evidence status without implying that the claim is
confirmed or suitable for a high-risk alert.

The E2E remains offline. It does not contact Gmail, external providers,
Telegram, Railway or Pages, and never includes private creator media.
