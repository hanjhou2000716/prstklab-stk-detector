## Overlap decisions

1. Creator identities have one registry. The Railway JSON is a deployment
   bundle and must remain byte-equivalent; it is not edited as a second source
   of truth.
2. FinancialJuice is a discovery/relay source. Its vendor importance controls
   notification priority only; it cannot change PRStK risk or bypass official
   and market evidence gates.
3. Official news has one provider registry. Discovery feeds (Google News and
   Anue) remain discovery-only and cannot enter the official evidence catalog.
4. Railway root-only compatibility code may route mail or load a generated
   classifier, but it must not implement a second parser, event classifier,
   release gate or Telegram policy. The health response exposes the active
   mode and classifier hashes so a deployment can be rejected when it drifts.
5. All notification paths converge on the release gate, shared lifecycle and
   delivery receipt contract. A source failure, missing release, stale quote or
   unverified event remains fail-closed.
