# 台股璞玉價值：當期品質＋低熱度 v2

台股璞玉價值的目前規則版本是 `tw_value_current_quality_v2`。它使用 TWSE OpenAPI 的六類損益表與六類資產負債表批次端點；每輪每個端點只取一次，整個股票池共用結果，且不呼叫歷史 MOPS 查詢。

## 可評估資料

- 最新同公司、同年度、同季別的基本每股盈餘（元）必須存在且為有限數值。
- 同一期間的「淨利（淨損）歸屬於母公司業主」與「歸屬於母公司業主之權益合計／總額」必須存在；不以集團總額代替母公司口徑。
- 年化獲利／期末權益估算為 `同年度累計歸屬母公司淨利 × 4 ÷ 季別 ÷ 同季末歸屬母公司權益`。權益小於等於零是不合格，不是缺漏。
- 股票池仍為 0050＋0051；行情沿用 63 根日線、至少 40 根有效日線與官方普通股股數。

## 選擇

兩項品質條件都必須通過。平均成交金額、平均成交量、換手率及三個月報酬率四項低熱度條件中，至少三項低於完整股票池第 90 百分位才列正式候選；通過一或兩項可列觀察名單。排序以條件數、未四捨五入品質估算值、股票代號決定。

官方端點或快取不可驗證時，報表保留完整診斷並標示缺漏；不以部分股票池宣稱完成。快取保存來源 hash、財報期間、解析版本與原始核對時間，重用快取不刷新核對時間。舊 MOPS 快取與歷史研究 release 僅供歷史版本讀取。
