# MOPS 歷史資料分批建檔

台股「璞玉價值」需要每家公司最近三年 EPS、最近四季 EPS、股利與其他公開條件的完整歷史資料。MOPS 端點需要逐家公司、逐期間查詢，冷快取時一次驗證全市場會超過 Actions 的工作時間上限。

正式排程現在每輪固定最多補 50 檔：

- 尚未成功的公司優先處理；暫時失敗的公司遵守 6 小時冷卻。
- 本輪未完成時，研究報表仍是 `building`／`diagnostic`，不產生正式候選，也不觸發高風險通知。
- 已完成的 MOPS 快取會以 cache-only data release 保存；不會把部分研究報表發布成正式 Pages release。
- 下一輪從快取繼續，不會重新從 150 檔起算。
- `mops_max_refresh=0` 僅供人工完整稽核，不應用於一般排程或工作流 dispatch。

因此「歷史核對中」代表建檔仍在前進，不等同於沒有候選；待全市場完成且通過 production research gate 後，才會建立新的正式研究 release。

## 回滾

回滾本修復 PR 只會恢復原本的工作流批次設定與快取保存行為；既有 `data-release` 快取不需刪除，下一次成功的完整研究 release 仍可正常取用。
