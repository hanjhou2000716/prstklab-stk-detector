# 黑天鵝與重大正向事件快訊規則

本規則只用於公開資訊整理與教育性市場觀察，不構成投資建議。

## 來源與確認

- 僅接受已授權的金十 MCP 快訊，並由 Railway 以 HMAC 簽章送至 GitHub。
- GitHub 會驗證簽章、事件 ID 與時間格式；未通過者不寫入 Mini App、也不發送 Telegram。
- 報導中的「傳聞」、「評論」或一般波動，不會單獨被當成黑天鵝或重大正向事件。

## 事件分級

### 黑天鵝／重大風險

僅在快訊明確包含重大地震或海嘯、核事故、大規模系統中斷、金融危機／銀行擠兌、重大交易所資安事故或熔斷等高衝擊事實時觸發。

Mini App 會呈現事件、可能連動市場及持續觀察重點；Telegram 只發 30 字內的中性標題。

### 重大正向事件

僅在快訊明確提及停火／和平協議、關稅正式豁免或取消、重大降息等已發生或已公告的事件時觸發。此分類代表風險溢酬可能變化，不預設市場必然上漲。

## 發送頻率與去重

1. 每個外部事件 ID 只會發送一次。
2. 同分類事件預設 30 分鐘冷卻，避免同一新聞的多個改寫版本連續推播。
3. 冷卻期間只有出現新的升級事實（如災情、供應中斷、攻擊擴大或停火破裂）才允許重新發送。
4. 收到事件後會重新整理公開報價；卡片只敘述可核對的價格與可能連動，不把相關性寫成因果或操作指令。

## 例外與資料缺口

若授權來源、簽章、報價或官方後續資料無法取得，系統會保留資料狀態，不以舊資料推論即時市場影響。
