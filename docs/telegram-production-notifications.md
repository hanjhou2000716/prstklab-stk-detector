# Telegram production notification policy

> Current policy: scheduled, official-event and emergency production use one
> release-gated `sendPhoto` message. The scoped `photo_test` workflow remains a
> single-recipient diagnostic path.

Production scheduled and event notifications use one `sendPhoto` after the
release gate succeeds. The caption is generated by the shared short-caption
contract (at most 40 Unicode characters), displayed above a fixed 1080x1350
PNG, and includes a Mini App inline button whose query includes the alert,
release, snapshot, observation and view identifiers. Full evidence,
provenance, market context and research details remain in the release
referenced by the button.

The renderer is fail-closed: a missing browser, invalid dimensions, blank
image, or missing required fields blocks delivery and records the renderer
error type. It never sends a solid or blank fallback card. The scoped photo
smoke test still requires one explicit test chat ID and must never use the
normal broadcast list.

## Rollback

Revert the production transport commit and re-run the release gate. The photo
smoke test is independent and can remain available for renderer diagnostics.
