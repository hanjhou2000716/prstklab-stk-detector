# 四報證據式內容契約

本次改版把 PDF 範例中可驗證的編排結構保留為「事件／行情證據 → 市場反映 → 重要性 → 後續確認」，不複製範例中無法由現有資料證明的因果或交易建議。

## 來源逆向對照

| 範例內容角色 | 現有 release-bound 資料 | 本次呈現 | 缺資料時 |
| --- | --- | --- | --- |
| 台股行情與盤面 | `indices`、`quotes`、`taiwan_market_statistics` | 台股卡行情列、成交值／廣度／法人摘要 | 隱藏公開行情列，缺口留在系統分析 |
| 隔夜科技與亞洲市場 | `indices`、`quotes` 的 Nasdaq、費半、日經、韓國綜合 | 半導體卡與報別重點 | 只保留有效行情，不把缺值當中性 |
| 利率、匯率與商品 | `macro_quotes` 與同次 snapshot 的行情 | 外部風險卡 | 以具體缺口降級，不阻塞其他有效卡片 |
| 公開事件 | digest 已通過資格與正規化的 `themes` | 事件主體、發生內容與來源引用 | 回退到行情／統計證據，不從截短通知反推 |
| 後續確認 | theme 的 `stock_observation`／催化劑欄位與報別 focus | 展開詳解的「後續確認」 | 顯示下一個可核對資料時點，不虛構日期 |

來源名稱出現在 release 的證據欄位時，才會進入引用；本次沒有新增未驗證的 API、付費資料源或新聞供應商。BLS／Fed 等官方日程保留為後續可接入的免費來源候選，必須先完成取得、時間、單位與失敗處理契約，才可進入正式 snapshot。

## 四報 focus

- 06:00 晨報：隔夜美股與全球變化、主要事件及今日日程。
- 08:45 台股盤前：最近台股收盤、法人與隔夜科技及匯率。
- 14:20 台股盤後：當日價格結構、成交廣度、法人與收盤事件。
- 21:00 美股盤前：台亞收盤、已發布總經資料、美國日程與科技事件。

每張卡的首屏最多三項重點，詳解固定提供「發生什麼、市場反映、為何值得注意、後續確認」四段結構。資料限制與來源採可展開方式呈現，避免以模板文字填滿首屏。

## 相容與安全邊界

- `narrative` 是新增欄位；既有 `facts`、投遞資格、canonical event key、ledger、Deep Link 及歷史 artifact 不改寫。
- 摘要只讀 digest 的已正規化主題與同次行情，不讀 raw provider prose，不自行補因果。
- 證據引用只投影來源、標的、資料時間與必要連結，排除 observation ID、郵件內容、地址及憑證。
- 新版前端只在 narrative 存在且契約完整時啟用；舊 artifact 仍由既有 fallback 讀取。
