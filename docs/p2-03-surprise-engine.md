# P2-03：總經 Surprise Engine

`calculate_surprise()` 將公布值、預期值、前值、前次修正與歷史標準差分開處理：

- 預期值缺失時輸出 `unknown`，不填入假設值。
- 有預期值才計算 surprise；有歷史標準差才計算 z-score。
- 前值與修正值另列 `revision`，不混進 surprise。
- `first_market_reaction()` 只描述事件前後的實際價格變動與相對基準，不做方向預測。

通知內容應先呈現「高於／低於預期、與前值差異、第一反應」，再由事件傳導模組根據證據輸出市場觀察。任何缺資料都應標示證據不足。

回滾：撤回本 PR 即可移除計算器；既有官方事件摘要不受影響。
