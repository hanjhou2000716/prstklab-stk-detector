# P1-03／P1-04：標的主檔與資料品質

這一批將跨市場標的辨識與資料品質判斷從各個抓取流程抽出，作為研究、行情卡與快訊共用的安全邊界。

## Instrument Master

`src/instrument_master.py` 以穩定的 `instrument_id` 保存市場、資產類型、幣別、時區、別名、交易所代碼與上市期間。`resolve()` 會先正規化大小寫、空白與符號，再依市場及 `as_of` 日期篩選；同一查詢對應多個標的時會拒絕解析，避免把 `TSM`、`2330`、台積電或指數誤配到錯誤市場。主檔可用 `save()`／`load()` 以 JSON 保存，之後可替換為版本化資料表。

## Data quality gate

`src/data_quality.py` 對每一筆觀測計算 0–100 品質分數，納入可用性、時效、完整度、交叉核對、解析信心與延遲。結果分成 `fresh`、`recent`、`stale`、`unavailable`，並提供兩個獨立閘門：

- `display_eligible`：資料仍有足夠證據時可顯示；過期資料可保留卡片但必須標示狀態。
- `alert_eligible`：只有新鮮且完成第二來源核對、分數達標時才能觸發警報。

這能避免「舊報價仍顯示為即時」及「來源未核對卻升級高風險」的矛盾。後續 P1-05 會把各市場的官方／公開來源優先順序接到同一品質評分器。
