# P0-02：台灣行情來源與日期語意

本批修正台股行情契約的來源與核對資料形狀：

- TAIEX 現貨由 TWSE MIS 提供，TAIFEX TXF 只作方向核對，不把期貨點位當成現貨價格。
- TPEx 官方收盤、TWSE MIS 備援與 Yahoo 備援保留各自來源與日期，不再混稱為同一筆即時報價。
- `crosscheck_sources` 統一為陣列；舊版 `{provider: observation}` 會在契約邊界正規化成帶有標籤、URL、時間與數值的陣列。
- 只有日期沒有時間的兩個收盤觀測，會以同一交易日判定為可比；不同日期不會假裝同步。
- Mini App 可同時使用 `quote_date`（行情日期）、`quote_time`（觀測時間）與 `technical_context.as_of`（技術區間日期）。

## 失敗時的行為

任何官方來源缺失、時間不一致或方向不一致，都會保留卡片並將核對狀態標為未核對／延遲，禁止觸發即時警報；不會用另一市場的點位補值。

## Rollback

回退本 PR 可還原舊的核對陣列處理，不會刪除既有快照。若回退後仍有來源矛盾，應暫停警報並優先修復資料，而非手動改寫數值。
